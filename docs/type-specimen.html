Three ways the shop could talk, set on the real copy.

Each panel is the same storefront: the wordmark, the hero line from the landing page, the station signs from the room, a paragraph and a button. Read them like a customer walking in, not like a font menu. Pick the one whose voice you'd put on the awning.

Wordmark is set live in the display face; the outlined SVG versions are in assets/logo/. Colors are the site palette and never change between panels, so only the type is on trial.
